\# AI-Based Thread Hunting



An AI-based project for detecting and analyzing suspicious

network activity.



\## Requirements

\- Python

\- Internet connection for downloading required assets



\## Installation



1\. Clone this repository:



&#x20;  git clone https://github.com/purusoth1261/Ai-Based-Thread-Hunting.git



2\. Open the project folder.



3\. Install dependencies:



&#x20;  pip install -r requirements.txt



4\. Start the application:



&#x20;  python app.py



Note: The trained model and dataset must be available in their

expected local paths before running the application.
